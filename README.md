# 🏋️ IronJaw

Landing page responsiva para uma academia fictícia desenvolvida com HTML, CSS e JavaScript.

## 📖 Sobre o Projeto

IronJaw é uma landing page criada para simular a presença digital de uma academia moderna. O projeto foi desenvolvido com foco em design responsivo, experiência do usuário e animações suaves, apresentando informações sobre a academia, seus diferenciais, planos e localização.

A aplicação segue a metodologia **Mobile First**, garantindo excelente usabilidade em smartphones, tablets e desktops.

## 🚀 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* ScrollReveal
* Google Maps API

## ✨ Funcionalidades

* Layout totalmente responsivo
* Desenvolvimento Mobile First
* Menu de navegação para dispositivos móveis
* Navegação suave entre seções
* Animações de scroll utilizando ScrollReveal
* Integração com Google Maps API
* Design moderno e intuitivo

## 📱 Responsividade

O projeto foi construído priorizando dispositivos móveis e posteriormente adaptado para telas maiores, proporcionando uma experiência consistente em diferentes resoluções.

## 🎯 Objetivo

O principal objetivo deste projeto foi praticar conceitos fundamentais do desenvolvimento front-end, incluindo:

* Estruturação semântica com HTML
* Estilização avançada com CSS
* Manipulação do DOM com JavaScript
* Criação de animações para melhorar a experiência do usuário
* Integração de APIs externas
* Desenvolvimento responsivo utilizando Mobile First
